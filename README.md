# 탱클 피젯

브라우저에서 돌아가는 닫힌 고리 탱클 피젯 토이. 폰에서 손가락으로 비틀어 노는 용도이고,
홈 화면에 설치하면 오프라인으로도 동작한다.

## 어떻게 만들어져 있나

탱클은 90° 꺾인 똑같은 조각들이 이어진 것이고, 각 연결부는 **튜브 축을 중심으로 한 회전
1자유도**만 갖는다. 그래서 조각이 16개면 전체 상태는 **각도 16개**가 전부고, 모양은 거기서
순방향 운동학으로 결정론적으로 나온다. 물리 엔진은 쓰지 않는다 — 실제 탱클은 관절 마찰
때문에 민 곳만 움직이고 나머지는 모양을 유지하는 **준정적** 물체라서, 중력 달린 강체
시뮬레이션을 붙이면 오히려 축 늘어져 탱클답지 않아진다.

닫힌 고리라 각도들이 자유롭지 않고 **루프 폐쇄 제약 6개**를 만족해야 한다. 매 프레임
감쇠 최소제곱(DLS) 뉴턴으로 그 제약 위에 되돌려 놓는다. 이때 쓰는 가중치가 손맛을 정하는
핵심이다 — 손가락이 잡고 있는 관절에 큰 가중치를 주면 그 관절은 잘 안 밀리고 보정이
나머지 고리로 퍼져나가서, 한 곳을 비틀면 고리 전체가 꿈틀거리며 받아주는 느낌이 난다.

그 밖에:

- **강체 드리프트 제거** — 폐쇄 보정에는 모양 변화와 "고리가 통째로 움직인 양"이 섞여 있다.
  뒤쪽은 좌표 표현의 문제일 뿐인데 화면에서는 전부 헤엄치는 걸로 보인다. 매 프레임 그
  성분만 최소제곱으로 뽑아 화면 변환에서 되돌린다.
- **자기충돌** — 붙어있지 않은 조각들을 캡슐로 보고, 겹치면 관절공간에서 밀어낸다. 그다음
  폐쇄 투영이 받아주므로 둘이 싸우지 않는다.
- **연쇄 쓸기** — 손가락이 쥔 조각을 앞지르면 그 관절을 관성째 놓아주고 다음 조각을 집는다.
  쓸면 관절들이 차례로 풀려난다. 한 관절이 특이점에 걸려 잠겨도 손가락이 자연히 다음으로
  넘어간다.
- **특이점** — 고리가 평평하거나 완전히 접힌 자세에 가까워지면 더 못 움직인다. 버그가 아니라
  실물도 그렇다. 야코비안의 조건수를 보고 가까워질수록 뻑뻑해지게 했다(좌상단 막대).

### 조각 수

굽힘 변환 B가 `B⁴ = 항등`이라 조각 수가 4의 배수면 폐쇄 해가 자동으로 존재한다. 다만 그
해는 같은 원을 여러 바퀴 겹쳐 도는 퇴화 상태라 쓸 수 없어서, 랜덤 초기값에서 솔버로 제대로
된 모양을 찾는다. 18처럼 4의 배수가 아닌 수가 닫히는지는 보장되지 않는다 — 패널에서 조각
수를 바꾸고 좌상단 **폐쇄오차**가 `0`에 머무르면 그 수는 닫히는 것이고, 숫자가 튀면 아니다.

## 폴더

```
tangle.html      소스. 여기만 고치면 된다
build-pwa.ps1    tangle.html -> docs/index.html
serve.ps1        docs/ 를 http://localhost:8765 로 띄우는 정적 서버
docs/            빌드 결과. GitHub Pages가 서빙하는 폴더
```

`tangle.html`은 문서 뼈대(`<!doctype>`, `<head>`)가 없다. Artifact 플랫폼이 퍼블리시할 때
붙여주기 때문이다. `build-pwa.ps1`이 그 부분과 PWA 설정을 더해 `docs/index.html`을 만든다.

## 고치고 다시 올리기

```powershell
.\build-pwa.ps1          # tangle.html -> docs/index.html
.\serve.ps1              # http://localhost:8765 에서 확인
```

바꾼 걸 올릴 때는 **`docs/sw.js`의 `CACHE` 값을 반드시 올릴 것.** 안 그러면 이미 설치한
폰은 서비스워커 캐시에 있는 옛 빌드를 계속 쓴다.

주의: `build-pwa.ps1`은 `Get-Content -Raw -Encoding UTF8`로 읽는다. `-Encoding UTF8`을
빼면 Windows PowerShell이 시스템 코드페이지로 읽어서 JS 문자열 안의 한글까지 깨뜨리고,
그대로 문법 에러가 난다.

## 배포

GitHub Pages: Settings → Pages → Source `Deploy from a branch`, Branch `main` / `/docs`.
`docs/.nojekyll`이 있어야 Jekyll이 파일을 건드리지 않는다.

경로는 상대 경로로만 써서 `user.github.io/저장소이름/` 같은 하위 경로에서도 그대로 동작한다.

## 아직 안 된 것

- iOS에는 진동 API가 없다. 아이폰에서는 소리가 유일한 촉각 대체재다.
- 자기충돌은 강체 충돌이 아니라 "겹치면 밀어내기"라서 빠르게 밀면 살짝 파고든다.
- 두 손가락 앵커 비틀기, 재질/테마, 모양 URL 공유는 아직 없다.
